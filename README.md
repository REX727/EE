# Introduction to Electrical Engineering

A bilingual, illustrated introduction to circuits, ESP32 and robotics.
中英雙語圖解教材：7階段、28單元，按自己的進度學習。

- index.html：繁體中文
- en.html：English
- 28 conceptual diagrams in each language, two component identification illustrations, and interactive resistor/PWM examples.
- 每課包括實驗、預設收起的自我檢查、中英術語及完整AI測驗提示。
- Both languages share local browser progress. Export a backup before changing devices or clearing browser data.

## Read locally / 本機閱讀
Open index.html or en.html. For full browser features, serve this folder with a local static web server.
All assets are included and use relative paths. No accounts, backend, API keys or AI connection are needed.

## Limits / 使用限制
The diagrams explain concepts; follow the documentation of your exact hardware for wiring.
AI-generated component illustrations are for identification, not pinouts, scale or model specifications.
Hardware examples have not been tested on your physical boards or motors.

Image creation method and prompts: IMAGE-NOTES.md.
